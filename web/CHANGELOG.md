# 운영 웹 변경 이력

형식: [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/) · 버전: [SemVer](https://semver.org/lang/ko/) `MAJOR.MINOR.PATCH`
버전은 `python tools/bump_version.py web patch|minor|major` 로만 올립니다(이 파일과 `lib/version.php` 를 함께 갱신).
배포는 `tools\deploy_web.ps1` (외부 https://pms.utinfo.co.kr/stock).

> 버전 체계: 최초 관리 버전부터 `1.x.y` (초기 개발 중 임시 번호 `0.x.y` 는 첫 자리만 1로 바꿔 이어서 표기). 운영 웹 버전은 서로 독립적으로 올립니다.

## [1.4.0] - 2026-09-23
### 추가
- **리서치** 대메뉴 신설 — DART 재무데이터와 Claude 재무분석 리포트를 보는 **순수 조회 · 연구용** 화면.
  계좌 · 주문 · 알고리즘과 전혀 연결되지 않으며(라우트에 `account` 미지정 → 계좌 선택 UI 없음) 쓰기도 하지 않는다.
  두 화면 상단에 "이 리포트는 참고용이며 매매를 자동으로 실행하지 않습니다" 면책 문구를 고정 노출
- **리서치 → 재무분석 리포트**(`research.reports`) — 리포트가 있는 종목을 **종목별 최신 1건**씩 나열
  (요약 · PER · PBR · ROE · 부채비율 · 리포트일 · 재무기준). 요약 카드, 종목 검색 · 리포트 상태 ·
  PER/PBR/ROE/부채비율 범위 필터, 정렬(리포트 최신순 / PER 낮은순 / PBR 낮은순 / ROE 높은순 / 부채비율 낮은순 등 화이트리스트)
- **리서치 → 기업 재무분석**(`research.company`) — 종목 검색 목록에서 종목을 고르면
  최근 5년 재무제표(보고서구분 한글 라벨 · 억원 표기 + 원 단위 원본 `<details>`),
  최근 밸류에이션(계산 기준일 · `financial_asof` 병기), PER/PBR 추이 SVG(30~365일)와 일별 값 표,
  **Claude 재무분석 리포트 전문**(요약 + 본문, 개행 유지), 리포트 이력을 보여준다
- `api.php` 조회 엔드포인트 `research_stocks` · `research_company` 추가(GET 전용, 리포트 본문 제외).
  하루 1회만 바뀌는 데이터라 대시보드 30초 자동 갱신에는 넣지 않았다
- `tools/demo_data.py` 에 기업 재무분석 데모(종목코드 접두 `DEMOF`, 재무 12건 · 밸류에이션 50건 ·
  리포트 3건(정상 2 · 오류 1) · corp_code 2건) 적재/삭제/상태 확인 추가

### 변경
- `filter_form_close()` 가 화면별 추가 파라미터를 초기화 목록에 받을 수 있도록 확장(기존 호출부 영향 없음)
- 서버사이드 SVG 라인 차트(`svg_line_chart`)에 소수 자릿수 옵션 추가 — PER/PBR 처럼 소수가 의미 있는 지표 지원
- 범위 필터용 숫자 파라미터 검증 헬퍼 `clean_num()` 추가

## [1.3.0] - 2026-09-23
### 추가
- 전략 → 산업 트렌드에 **"지금 다시 조사"(수동 재조사 요청) 버튼** 추가 — **admin 전용**, POST + CSRF 필수.
  누르면 `trend_scan_request` 에 요청 한 줄만 남기며(웹의 유일한 업무성 쓰기), 주문 · 설정 · 알고리즘은 전혀 바뀌지 않는다.
  중복 클릭 방지(같은 세션 2분 쿨다운 + 최근 3분 내 수동 시도가 있으면 버튼 잠금), 요청 후 안내 배너
- **스캔 시도 이력**(`trend_scan_attempt`) 표 추가 — 예약 · 수동을 포함한 모든 시도를 실패까지 최신순으로 표시
  (시각 · 구분 · 요청자 · 상태 · 웹검색 · 후보 · 토큰 · 지연 · 오류 + 행별 `<details>` 조사 원문 전문)
- 실행 이력 · 오늘 스캔 줄에 **구분(예약/수동) 배지와 요청자** 표시, 필터에 **구분** 추가
- `tools/demo_data.py` 에 `trend_scan_attempt`(정상 2 · 부분 성공 1 · 오류 1 / 예약 2 · 수동 2)와
  `trend_scan_request`(status=done) 데모 적재/삭제/상태 확인 추가

### 변경
- 상태 배지에 툴팁 지원 — "부분 성공"에 웹 검색 실패 가능성 안내가 마우스 오버로 표시
- 페이지네이션(`render_pager`)이 한 화면의 표 두 개를 각각 넘길 수 있도록 파라미터 이름을 받도록 확장

## [1.2.1] - 2026-09-22
### 수정
