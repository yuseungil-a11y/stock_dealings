# 서버(stock_svr) 변경 이력

형식: [Keep a Changelog](https://keepachangelog.com/ko/1.1.0/) · 버전: [SemVer](https://semver.org/lang/ko/) `MAJOR.MINOR.PATCH`
버전은 `python tools/bump_version.py server patch|minor|major` 로만 올립니다(이 파일과 `stock_svr/__init__.py` 를 함께 갱신).

> 버전 체계: 최초 관리 버전부터 `1.x.y` (초기 개발 중 임시 번호 `0.x.y` 는 첫 자리만 1로 바꿔 이어서 표기). 서버 버전은 서로 독립적으로 올립니다.

## [1.2.2] - 2026-09-20
### 변경
- 서버 프로그램 아이콘을 주식 상승 이미지(오르는 캔들 + 상승 화살표)로 변경(창·작업표시줄·exe 파일). `python tools/make_icon.py` 로 재생성

## [1.2.1] - 2026-09-20
### 수정
- 알고리즘 탭 [유효 한도 미리보기]와 자동거래 시작 확인창이 계좌 번호 대신 함수 자체를 넘겨 총자산이 항상 "확인 불가"로 나오던 문제 수정
- 알고리즘 탭 파라미터 폼을 마우스 휠로 스크롤할 수 있게 함
### 테스트
- 실제 시각(장 시간)에 의존하던 파이프라인 테스트를 시각과 무관하게 고정, 테스트용 가짜 앱을 실제 App 과 같은 구조(계좌 번호는 메서드)로 정정

## [1.2.0] - 2026-09-20
### 추가
- 종목 유니버스 필터(`universe_filter`, 기본 꺼짐): 시가총액 순위(시장별/합산), 코스피·코스닥 선택, 1주 최소/최대 가격, 최소 시가총액, 우선주·스팩·관리/거래정지/투자경고 제외, 신규 진입(선택 시 물타기 포함) 매수에만 적용, 마스터 갱신 지연 시 신규 매수 차단
- 알고리즘 탭: [대상 종목 미리보기], [유효 한도 미리보기](총자산 대비 종목당 한도 vs 최소 주가 경고), 자동거래 시작 확인창에 유니버스·한도 경고 표시
- 서버 창 우측 상단·창 제목·시작 로그·하트비트에 버전 표시(웹 상단이 서버 버전을 함께 표시), 빌드 시 `VERSION.txt` 기록
### 변경
- 종목마스터 신선도 점검을 장 상태와 무관하게 300초 주기로 수행(기동/장 시작 전에도 하루 1회 갱신 보장)

## [1.1.0] - 2026-09-20
초기 버전(실계좌 조회 전용 관찰모드 + 주문 게이트).

### 추가
- 키움 REST/WebSocket 연동(토큰·재연결·연속조회·호출 간격 제어), 계좌·시세·주문·체결 동기화
- 알고리즘: 리스크 가드(총투입/종목당 한도(원·총자산 %), 손절, 일손실, 일주문횟수, 매매시간), 모멘텀 스크리닝, 변동성 돌파, 분할매수(물타기), 이동평균 크로스 필터
- Claude 거부권 필터(`claude_advisor`, 기본 꺼짐) — 매수 신호만 검토
- 자동거래 시작/중지 버튼, 긴급 미체결 취소, 주문 게이트(order_enabled / real_trading_confirm)
- 알고리즘 선택·파라미터 편집 UI(DB 관리, 변경 이력), 상태 아이콘, 주요 기록, 로그 7일 보관
- 거래 기록 강화: 신호가·신호맥락·파라미터 스냅샷, 주문 상태 이력(`order_event`), 거부 사유, 이벤트/API 오류 365일 보관
- 상장폐지·거래불가 종목 매매 제외, 다중 실행 방지 락
### 보안/안전
- 주문 API 무재시도, 환경·모드 불일치 차단, 게이트 변경 확인(`REAL`), 리스크 조회 실패 시 매수 차단, 리스크 가드 소실 시 전 주문 차단
