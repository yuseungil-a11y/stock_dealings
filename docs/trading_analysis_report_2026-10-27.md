# 자동매매 운영 분석 리포트 (2026-10-27)

- 분석 대상 계좌: 3508424711 (실전, env=real)
- 분석 기간: 2026-09-18 ~ 2026-10-27 (ka10170 당일매매일지 기준 실거래일 16일)
- 분석 방법: `daily_trade_summary`(실현손익), `orders`/`executions`(주문·체결), `holding`/`account_balance`(평가·자산), `algorithm`/`algorithm_selection`(전략 on/off) 테이블을 직접 SQL 조회
- 작성 배경: "수익률이 좋지 않아 거래 패턴을 분석하고 앞으로 운영 방향을 알려달라"는 요청에 따른 1회성 분석

## 1. 대시보드 "-30%대" 수익률의 실체

대시보드에 찍히는 평가손익 **-363,442원**(2026-10-27 기준)의 **99%(-361,050원)는 040670 (폐)와이즈파워 한 종목**에서 나온다.

- 이 종목은 `orders`/`executions`/`trade_ledger` 어디에도 기록이 없다 — 이 자동매매 시스템이 산 것이 아니라 **봇 가동 이전부터 계좌에 있던 상장폐지 종목**이다.
- 알고리즘도 이미 "거래불가 종목 제외" 처리해 손을 대지 않고 있다(매매 불가, 회복 불가).
- 포트폴리오 비중 29.8%(`poss_rt`)를 차지하는 죽은 자산이 전체 수익률 숫자를 심하게 왜곡하고 있다.

이를 제외하고 **실제 봇이 만든 성과**만 분리하면:

| 구분 | 금액 |
|---|---|
| 실현손익 합계 (9/18~10/27, 수수료·세금 반영 후 순액) | **-108,891원** |
| 현재 보유 중인 "살아있는" 종목들의 평가손익 합 (와이즈파워 제외) | **-19,398원** |
| 순수 매매 성과 (실현+평가) | **약 -128,289원** |
| 총 매도거래금액 | 2,404,980원 |
| 순수 매매 성과 / 총 매도거래금액 | 약 **-5.3%** |

참고: 9/19~10/27 사이 계좌 자산이 187,200원→922,693원으로 늘었는데, 중간 몇 차례 급등 구간(9/20, 9/25, 특히 10/7 555,081→1,036,767)은 거래 손익이 아니라 **입금으로 추정**된다. 입출금 추적 기능이 없어 추정치이며, 정확한 수치는 [[계좌 입출금 기능 백로그]] 구현 후 확인 가능.

## 2. 손실 원인 분석 — 구조적 저승률

**승률 31% (11승 24패, 35건 매도 기준)**가 핵심 원인이다.

손절/익절 구조:
- `risk_guard` 손절: **-10%** 고정선 도달 시 전량 매도 — 15건 전부 손절 (갭다운으로 실제 체결은 -10.0%~-13.3%까지)
- `take_profit`: **+7%** 도달 시 보유량의 50%만 매도 후 잔량은 ATR 트레일링 — 12건

승률 31%에 "손절 -10% : 익절 +7%(절반)" 구조를 대입한 기대값 ≈ 0.31×7% − 0.69×10% ≈ **-4.7%/거래**. 실제 결과(약 -5.3%)와 거의 일치 — 즉 지표 문제가 아니라 **전략 자체가 구조적으로 마이너스 기대값**이다.

### 원인: 추세/품질 필터 없이 급등주 추격

`momentum_screen`(전체 매수 체결의 대부분, 29건)의 매수 사유 로그:

> "당일상승 25.09% + 거래량비율 50.57% 돌파", "당일상승 12.13% + 거래량비율 102.68% 돌파", "당일상승 21.77% + 거래량비율 74.26% 돌파"

**이미 급등·급증한 종목을 추세/품질 필터 없이 그대로 쫓아 사는 구조**다. `algorithm_selection` 조회 결과 다음 두 필터가 꺼져 있다:

| 필터 | 상태 |
|---|---|
| `universe_filter` (시가총액·주가 필터) | **OFF** |
| `ma_cross_filter` (이동평균 크로스/추세 필터) | **OFF** |
| `fundamentals_filter` (재무 건전성) | ON |
| `claude_advisor` (Claude 거부권) | ON |

과열 종목을 추세 확인 없이 매수 → 며칠 뒤 갭하락으로 한꺼번에 손절당하는 패턴이 반복됨:
- 2026-10-13: 6종목 동시 손절
- 2026-10-26: 4종목 동시 손절 (09:06 시점에 몰림)

## 3. 별개로 발견한 운영 버그

`volatility_breakout` 매수 시도의 **83%(34/41건)가 주문 실패**:

| 실패 원인 | 건수 |
|---|---|
| "장이 열리지않는 날입니다" (휴장일 주문 시도) | 29건 |
| "단가를 입력하지 않는 호가입니다" (주문 파라미터 오류) | 5건 |

금전 손실은 없었음(주문 자체가 거부됨)이나, 로그 오염·API 호출 낭비·신뢰성 저하 문제. 주문 전송 전 개장일 체크가 누락된 것으로 추정.

## 결론

"수익률이 나쁘다"는 체감의 대부분은 **죽은 레거시 종목(상장폐지 와이즈파워) 하나** 때문이며, 실제 봇의 매매 성과는 작지만 꾸준한 손실(약 -13만원, 매도거래금액 대비 -5.3%)이다. 그 원인은 **추세/품질 필터를 꺼둔 채 급등주를 추격하는 momentum_screen의 구조적 저승률(31%)**이다. 필터 재활성화와 손익비 조정이 가장 효과가 큰 다음 단계로 판단된다.
